# AuraDesk

AuraDesk היא אפליקציית Windows מקורית להצגת וידאו, GIF, תמונה או דף אינטרנט כרקע חי מאחורי סמלי שולחן העבודה.

## מה כלול בגרסת ה‑MVP

- שלושה רקעים מונפשים מובנים: זוהר צפוני, ערפילית ואופק ניאון.
- ייבוא MP4, WebM, MOV, AVI, GIF, WebP, PNG ו‑JPG.
- הוספת דף אינטרנט לפי כתובת HTTPS.
- בחירת מסך יעד במחשב עם כמה מסכים.
- השהיה אוטומטית כאשר יישום אחר נמצא במסך מלא.
- השהיה בזמן עבודה על סוללה, השתקת שמע והפעלה עם Windows.
- סמל במגש המערכת להפעלה, השהיה, עצירה ויציאה.
- שמירת הספרייה וההגדרות בין הפעלות.

## הפעלה

להתקנה רגילה הפעילו את `AuraDesk-Setup-0.2.1.exe`. המתקין מאפשר לבחור תיקייה, יוצר קיצורי דרך ומוסיף מסיר התקנה ל‑Windows.

להפעלה ללא התקנה השתמשו ב־`AuraDesk-0.2.1-portable.exe`.

הקובץ אינו חתום בתעודת Code Signing מסחרית. לכן Windows SmartScreen עשוי להציג אזהרה בהרצה הראשונה; להפצה ציבורית מומלץ לחתום על קובץ ה‑EXE.

לפיתוח מקומי:

```powershell
npm install
npm start
```

לבדיקות ולבניית קובץ נייד:

```powershell
npm test
npm run dist
```

לבניית המתקין בלבד:

```powershell
npm run dist:installer
```

## הערות

- האפליקציה מיועדת ל‑Windows 10/11 בגרסת 64 סיביות.
- דפי אינטרנט מסוימים חוסמים הטמעה, הפעלה אוטומטית או תוכן מוגן. במקרה כזה עדיף להשתמש בקובץ וידאו מקומי.
- מצב האתר ב‑MVP אינו מעביר לחיצות עכבר דרך סמלי שולחן העבודה.
- סגירת החלון הראשי משאירה את הרקע פעיל במגש המערכת; בחרו “יציאה” מתפריט המגש כדי לסגור לחלוטין.

## פרטיות

הספרייה וההגדרות נשמרות במחשב בלבד. AuraDesk אינה אוספת מידע ואינה שולחת קבצים לשרת.
